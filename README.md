## Preview, check, and package

No dependency installation is needed. Node.js 24 supports the optional scripts. To preview the source:

```powershell
node scripts/serve.mjs
```

Open **http://127.0.0.1:4173** or **http://127.0.0.1:4173/cm/**. Direct local-file viewing also works: open `index.html` or `public-pages/cm/index.html`.

Build and validate:

```powershell
node scripts/build.mjs
node scripts/check.mjs
node --check app.js
node --check cm.js
```

Preview the generated site with `node scripts/serve.mjs dist`. While that server runs, `node scripts/check-http.mjs` checks public routes and confirms that private and unapproved paths return 404.

Create the portable upload package after building:

```powershell
node scripts/package.mjs
```

`drlong-website.zip` contains `index.html` at its root and `cm/index.html` beneath it. Upload its contents, or `dist/` contents, to a static host. Use `node scripts/build.mjs` as the build command and `dist` as the output directory. Never select the workspace itself as the public directory.
